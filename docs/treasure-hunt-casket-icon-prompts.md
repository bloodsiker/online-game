# Промпты для шкатулок «Кладоискателя» (6 тиров)

Отдельная линия от «трофейных шкатулок» (`docs/monster-drop-casket-icon-prompts.md`,
падают с монстров) и «сундуков локаций» (`docs/locked-chest-icon-prompts.md`) —
это награда за успешную сверку по карте сокровищ (`TreasureMapConfig::reward`,
share_items id 1960/1962/1964/1966/1968/1991). Технический чек-лист (прозрачный
фон, белая обводка + угасающее свечение, квадрат, читаемый силуэт) — тот же,
что у трофейных шкатулок, не сокращать при использовании. Мотив — свой,
привязан к названию тира (потёртая/старинная/загадочная/забытая/
легендарная/героическая), а не к уровню монстра.

Isolated on a fully transparent background, PNG format, item only, no background elements, no drop shadow.
