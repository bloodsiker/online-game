# Промпты иконок эликсиров алхимика

Один промпт на тип эликсира: одна иконка для всех тиров (Малый / обычный / Крепкий / Великий / Легендарный).
У каждого типа своя форма флакона, цвет жидкости и символ, чтобы на панели их можно было различить.

Каждый промпт = описание + общий хвост в конце файла.

Add a bright white outline around the complete outer silhouette and a moderately wide soft white magical glow, fading smoothly into full transparency. The glow must stay visible at small icon size without washing out details or forming an opaque background.

No text, letters, numbers, borders, watermarks, scenery, or backdrop. Fully transparent background (true alpha channel, not white, not a checkerboard). PNG, square 1:1, 1024×1024.
