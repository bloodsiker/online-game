# Экономика: деньги с монстров и цены Тир2/Тир3 брони — история решений

## v1 (изначальная) — decay со сбросом на границе тира

Деньги с монстра резко падали весь тир (лвл20→49: 134-268 → 94-187), а на границе следующего тира внезапно подскакивали обратно (лвл49→50: 94-187 → 530-1061). Не «плавный рост», а зигзаг.

## v2 — единая степенная кривая денег (без сбросов)

`MonsterStatFormulas::moneyRange()` (см. докблок в коде):

```
money(level) = referenceExp(20) × [15%, 30%] × (level / 20)^0.4363 × difficultyRatio
```

- Монотонный рост — деньги никогда не меньше, чем у монстра более низкого уровня.
- Показатель степени 0.4363 < 1 — та же форма, что уже используется в `ExperienceCurve::referenceMonsterExp` — рост есть всегда, но процент прироста сам плавно уменьшается.
- Подобран так, чтобы суммарный накопленный доход 20-89 lvl ≈ **30 000 000**.
- `difficultyRatio` сохраняет пропорциональность для мобов с `expMultiplier ≠ 1.0`.

Каскадно пересчитаны: `MonsterStatFormulas` (формула), 71 не-босс монстр lvl≥20 по всей игре (боссы с ручным exp/money не тронуты; 4 event-монстра — Дозорный Ворон/Метельный Дух/Кадильный Дым/Жертвенный Идол — money=0 вручную выставлено пользователем, формулой не перезаписывается).

## v3 — цены брони: чистый доход (net worth), а не валовый

Изначально (v2) цена слота считалась как 150% от ВАЛОВОГО дохода, накопленного с начала тира ЦЕЛИКОМ, не учитывая, что часть этого дохода уже потрачена на предыдущие слоты того же тира. Из-за этого поздние слоты были завышены в разы (Кольчуга «Титан», лвл90: 45.1М при валовом подходе).

**Исправлено по прямому указанию пользователя**: running-ledger модель — чистый капитал = валовый доход между чекпоинтами МИНУС цена уже купленной вещи на предыдущем чекпоинте (не восстанавливается):

```
netWorth += income(предыдущий_чекпоинт+1 .. этот_чекпоинт)
price(этот_чекпоинт) = netWorth × 1.5
netWorth -= price   // уходит в дефицит, как и задумано
```

Дефицит стабильно держится на ~33% от цены каждой вещи — не растёт безгранично, не схлопывается в 0. Игрок, который фармит ровно свой уровень, никогда не может позволить себе вещь сразу на разлоке — придётся либо доферминть, либо искать другой доход (донжи/квесты/аукцион).
