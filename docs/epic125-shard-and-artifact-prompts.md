Три прошлые формы осколков были угловатыми/рваными (common — обломок,
uncommon — гранёный шип, rare — хаотичный кластер шипов). Для epic-125 —
полная противоположность: гладкий закруглённый кристалл-капля/орб без
единого острого угла, с видимыми спиральными слоями под поверхностью.
