# Промпты для картинок боссов «Башни Восхождения»

20 клановых боссов данжа «Башня Восхождения» (dungeon_id=3, структура id=37).
Стиль — по образцу реальных монстров игры (Пепельный Скорпион, Терновый Волк,
Тлеющий Страж Глубин, см. `docs/ash-depths-event-prompts.md`): полноформатная
живописная полу-реалистичная dark fantasy иллюстрация существа в среде
обитания, квадратная композиция, без рамки, существо заполняет большую часть
кадра. Окружение каждого промпта поднимается выше по Башне от этажа к этажу.

Этажи 1-10 — стихийные/мифические темы (камень → пепел → лёд → яд → гроза →
призрак → кровь → астрал → пустота → титан-воплощение Башни). Этажи 11-20 —
после сюжетного поворота (Титан оказался не вершиной) уходят в надреальное:
окружение становится всё более нелогичным, ломающим архитектуру и законы
восприятия.
