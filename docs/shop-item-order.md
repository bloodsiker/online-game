# Перетаскивание товаров в админке структуры

На `/admin/structure/{id}` во вкладке «Магазин» каждая категория, включая «Без категории», имеет собственную кнопку «Сохранить порядок». Товары перемещаются за ↕ или клавишами ↑/↓ на маркере. Перетаскивание не переносит товар в другую категорию.

Используется существующее `shop_items.sort_order`: верхняя строка получает наибольшее значение, в соответствии с действующей сортировкой магазина DESC. Для равных значений задан дополнительный порядок по ID и в админке, и в обычном/премиум-магазине.

POST `admin.structure.info.shop_order` расположен до параметризованного `/shop/{shopItem}`, чтобы слово order не обрабатывалось как ID товара. Передаёт ID категории и полный список ID строк shop_items. `ReorderShopItems` блокирует структуру и строки категории, проверяет точное совпадение состава и атомарно обновляет только sort_order. Неполный/устаревший/чужой список отклоняется; другие категории, цены и лимиты не меняются. При SQL-ошибке вся сортировка откатывается. После сохранения открывается вкладка магазина.

Миграции не нужны; основная БД при разработке не изменялась. Проверки новой функции: 5 тестов, 30 assertions на SQLite `:memory:`, Pint, diff-check, Node-проверка синтаксиса и независимости перемещения/отправки списков разных категорий. Старый `BarterShopConfigurationTest` дал три отказа CSRF 419 до входа в контроллер; его код и авторизационная фикстура в рамках этой задачи не менялись.
