# Промпт для иконки «Кастет «Титан»»

Стиль — по образцу остальных 10 предметов сета «Титан»
(`docs/titan-set-icon-prompts.md`): колоссальная, грубо-тёсаная
экипировка из железа и гранита, тёмное вороненое железо с прожилками
серого камня, массивные грубые формы без изящества, тусклая бронзовая
окантовка. Как и у остального сета, тёмная тень намеренно убрана.

Один базовый рендер переиспользуется для всех 4 тиров редкости (цветной
фон/окантовка по тиру добавляются движком поверх прозрачного PNG).
