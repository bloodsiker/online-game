# Промпты для иконок сета «Архимаг» (Тир3, uncommon, маг-крит)

Общий арт-стиль сета: точная, ритуальная тёмная магия — не грубая сила, а прецизионный удар в нужный момент (крит-архетип). Тёмная лавандово-фиолетовая ткань и чёрная кожа, гравированные светящиеся руны/сигилы золотисто-белым светом (символ точности удара), холодные фиолетовые драгоценные камни. Единая палитра по всем 10 предметам: тёмно-фиолетовый/индиго + чёрная кожа + золотисто-белые светящиеся руны.

Каждый промпт уже включает фиксированный чек-лист (прозрачный фон/угасающее белое свечение/квадрат/читаемость силуэта) — **без тёмной тени снизу** (как у Титана и Призрачного; если для этого сета тень всё же нужна — скажите, уберу пункт "no drop shadow"). Не сокращать при использовании.
