# Промпты для иконок рецептов профессий и реагентов

## Чернила (Колдун)

Единый стиль: простая стеклянная бутылочка с открытым горлышком (без
крышки/пробки), мягкое рассеянное белое свечение вокруг предмета без
резкой границы. Прозрачный фон, лёгкая тень под предметом.

### Простые чернила (обычные)

```
A simple glass ink bottle with an open narrow neck, no cap, no cork,
no stopper of any kind, filled with plain dark grey-black ink, the
liquid catching a faint dull sheen.
A soft white glow surrounds the object, heavily diffused and feathered
with no hard edge or visible outline — the light gradually fades
outward from the silhouette in a smooth gradient, like a wide, gentle
soft-focus halo rather than a sharp border, subtly separating the
object from any background behind it.
Simple, bold silhouette, minimal fine detail beyond the soft glow,
strong value contrast, designed to remain crisp and readable when
scaled down to a small icon. Semi-realistic fantasy game item icon,
digital painting.
A small, soft drop shadow beneath the item to ground it, background
otherwise fully transparent. Isolated on a fully transparent background,
PNG format, no background scene, no ground, no table — item only.
No text, no UI elements.

Square composition, item centered and filling most of the frame, --ar 1:1
```
