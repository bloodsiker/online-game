# Порядок ингредиентов рецепта

На странице предмета в админке строки ингредиентов перемещаются за маркер ↕. Для клавиатуры: фокус на маркере и ↑/↓. Кнопка «Сохранить порядок» сохраняет последовательность отдельно от количества каждого ингредиента.

- Поле `share_recipe_has_items.sort_order`; при равенстве используется ID строки связи. Старые записи имеют 0 и остаются в порядке ID.
- Связь `ShareRecipe::items()` задаёт единый порядок для админки, кузни и мастерской. Новые ингредиенты добавляются в конец; копирование предмета сохраняет порядок рецепта.
- POST `admin.item.recipe.ingredient_order` передаёт полный список **ID строк связи**, а не ID предметов. UseCase блокирует рецепт и его ингредиенты и проверяет точное совпадение состава. Устаревший/чужой/неполный список не сохраняется; количества не меняются.
