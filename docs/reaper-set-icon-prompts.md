# Промпты для иконок сета «Жнец» (Тир3, uncommon)

Общий арт-стиль сета: тёмный жнец-палач/смерть — в противовес массивному «Титану» здесь худые, вытянутые, хищно изогнутые формы. Блэкened (вороненая до черноты) сталь с зазубренными, рваными краями, отделка потемневшей костью/слоновой костью, потрёпанные тёмные кожаные ремни, тусклые тёмно-багровые акценты (запёкшаяся кровь), лёгкий призрачный/потусторонний налёт. Единая палитра по всем 10 предметам: чёрная сталь + кость + тёмно-багровый.

Каждый промпт уже включает фиксированный чек-лист (прозрачный фон/тень/квадрат/читаемость силуэта) — не сокращать при использовании.
