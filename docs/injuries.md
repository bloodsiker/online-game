# Промпты для иконок травм

Единый стиль: сами бинты, свёрнутые в форму части тела — без видимой
кожи/лица, просто слой бинтов, повторяющий силуэт части тела. Пятна
крови нарастают по степени тяжести (лёгкая → средняя → тяжёлая).
Прозрачный фон, лёгкая тень под предметом.
