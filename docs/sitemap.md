# Общий sitemap

Адрес: `/sitemap.xml`. Это динамический маршрут Laravel, а не сохранённый XML-файл. На каждом запросе `SiteSitemap` объединяет данные `LibrarySitemap` и `ForumSitemap`, затем XML-шаблон выводит абсолютные URL и доступные даты изменения (`lastmod`). Отдельная cron-задача или команда генерации не нужны; новой записи достаточно появиться в БД.

`robots.txt` тоже формируется Laravel и содержит абсолютную ссылку на sitemap текущего сайта. В локальном Nginx для обоих маршрутов настроены исключения из обработки статических XML/TXT.

## Библиотека

- RU/UK главные страницы, бестиарий и карта мира.
- Опубликованные статьи в активных категориях, только для существующих переводов.
- Адреса статей: `/{locale}/library/{category}/{slug}` без лишних query-параметров.
- Черновики, будущие публикации, удалённые статьи, поиск и фильтры не включаются.

## Форум

- Главная `/forum`.
- Активные конечные разделы `/forum/section/{slug}`. Родительские заголовки с активными дочерними разделами не включаются, поскольку у них нет собственной страницы просмотра.
- Темы `/forum/topic/{id}` из активных веток. Неактивный родитель исключает всю ветку.
- Страницы разделов и комментариев, начиная со второй (`?page=2` и далее), без дублирующего `?page=1`.
- Количество страниц рассчитывается по реальному числу тем/сообщений и общим с `ForumService` размерам страниц: 20 тем или 15 сообщений.
- Закрытая для ответов тема и раздел с отключённым созданием тем/комментариев остаются публичными для чтения и включаются.
- Удалённые темы/сообщения, поиск, редакторы, действия авторизации и фрагменты `#post-...` не включаются.
- `lastmod` учитывает обновления темы и редактирование сообщений. Обычный просмотр увеличивает счётчик, сохраняя дату изменения контента.

Генерация не открывает страницы тем или статей, не увеличивает их просмотры и не создаёт гостевые сессии. Данные форума собираются пакетными запросами без отдельного SQL-запроса для каждой ссылки.
