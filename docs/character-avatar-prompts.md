# Промпты для аватаров персонажей

Аватары по расе/полу — сейчас в игре нет системы выбора аватара (`users.sex`
и `players.race_id` существуют, но нигде не используются для картинки); везде
захардкожен один `public/img/avatar/dark_elf.jpg`.

Первая версия промптов ориентировалась на стиль этого референса
(фотореалистичный 3D-рендер) — по отзыву пользователя получилось «слишком
реалистично, не по-игровому», поэтому стиль переведён на **ту же живописную
полу-реалистичную подачу, что и у остального контента игры** (см.
`docs/ash-depths-event-prompts.md`/`docs/tower-of-ascension-boss-prompts.md`):
квадратный портрет по плечи (bust-crop), драматичный направленный свет,
размытый тёмный фон, деталь доспеха/воротника на плечах, но с выразительным
живописным рендером вместо фотореализма.

По 5 аватаров на расу/пол — разные типажи лица (возраст, телосложение,
архетип класса), но единый визуальный язык.
