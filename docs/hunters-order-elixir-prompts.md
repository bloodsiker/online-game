# Эликсиры Ордена Охотников — промпты иконок

Форма флакона одинакова для всех трёх видов на одном тире и богаче с каждым тиром; вид эликсира определяют цвет жидкости и амулет на горлышке.
Иконка эффекта — одна на вид: её ставим всем 6 эффектам этого вида (`effects.slug = hunter_*_500 … hunter_*_5000`).
