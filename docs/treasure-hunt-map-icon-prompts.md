# Промпты для карт сокровищ «Кладоискателя» (6 тиров)

Единый house-style инвентарных иконок (как у гримуаров/осколков/печатей,
см. `grimoire-book-prompts.md`, `shard-prompts.md`): плоская насыщенная
2D-иконка, белое свечение по контуру, прозрачный фон. Готовая карта
(`share_items` id 1961/1963/1965/1967/1969/1990) — закрытый свёрнутый
свиток, а не раскрытая карта с рисунком местности (территория скрыта до
сверки, см. `docs/treasure-hunt.md`), поэтому мотив строится на материале
и печати свитка, эскалирующих по тиру: обычная бечёвка → потускневшая
бронза → тёмная магическая печать → вросшие в свиток лозы → сияющее
золото → багрово-золотой геройский реликт.
