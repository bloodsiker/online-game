# Промпты для фрагментов карт сокровищ «Кладоискателя» (6 тиров × 4)

Сейчас иконки фрагментов переиспользуют картинку целой карты (см.
`docs/treasure-hunt.md`). Эти промпты — под собственные иконки: 4 разных
куска одного и того же свитка, которые визуально читаются как части,
складывающиеся в готовую карту (`docs/treasure-hunt-map-icon-prompts.md`,
тот же материал/печать/перевязь на тир). Единая роль куска по номеру во
всех 6 тирах — чтобы I/II/III/IV были узнаваемы между тирами:

- **I** — кусок с печатью/краем, где должна быть печать (виден срез печати).
- **II** — средний кусок с рваным краем по диагонали, без печати и без хвоста.
- **III** — кусок, обёрнутый перевязью/бечёвкой/лентой этого тира.
- **IV** — хвостовой кусок со скруткой на одном конце и рваным краем на другом.

House-style — тот же, что у целой карты (прозрачный фон, белое свечение по
контуру), каждый промпт самодостаточен, не сокращать при использовании.
