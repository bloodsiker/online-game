# Промпты для новых монстров «Пепельных Предгорий»

Стиль — по образцу реальных файлов монстров (`Пепельный Скорпион`,
`Терновый Волк`, «Степной Шакал»): полноформатная (full-bleed, без
рамки) живописная полу-реалистичная иллюстрация существа в естественной
среде обитания, динамичная поза, тёмная атмосферная палитра, квадратная
композиция. Только 2 вида — «Пепельный Скорпион» это существующий вид
(новые тиры просто продолжают уже отрисованный облик, новый арт не
нужен), поэтому промпты только для двух НОВЫХ видов, по одному на
каждый из 2 тиров (как и у остальных монстров — тиры визуально
отличаются, не переиспользуют одну картинку).
