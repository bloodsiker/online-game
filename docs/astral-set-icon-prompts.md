# Промпты для иконок сета «Астрал» (Тир3, uncommon, маг-урон)

Общий арт-стиль сета: чистая разрушительная космическая мощь — не точность, а необузданная сила (маг-урон архетип). Глубокая полуночно-синяя/чёрная ткань, будто сотканная из пустоты космоса, бурлящая ярко-голубовато-белая звёздная/туманностная энергия, вырывающаяся сквозь швы и трещины материала, холодное серебро вместо золота (контраст с «Архимагом»). Единая палитра по всем 10 предметам: тёмно-синий/чёрный космос + ярко-голубовато-белое звёздное свечение + холодное серебро.

Каждый промпт уже включает фиксированный чек-лист (прозрачный фон/угасающее белое свечение/квадрат/читаемость силуэта) — без тёмной тени снизу (как у «Архимага»). Не сокращать при использовании.
