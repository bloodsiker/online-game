# Промпт для иконки «Секач палача» (одноручный топор сета «Палач»)

Общий арт-стиль сета (по образцу реальных файлов `Топор палача`/`Меч
палача`): тёмное чернёное железо с запёкшимися тёмно-красными кровавыми
прожилками и потёками вдоль лезвия, шипастое металлическое навершие
рукояти, рукоять обмотана тёмной кожей с металлическими кольцами,
грубая и зловещая эстетика палача-мясника, без изящных узоров.

Один базовый рендер на предмет переиспользуется для всех 5 тиров
редкости — цветной радиальный фон и зелёная окантовка на реальных
файлах добавляются движком поверх прозрачного PNG при отображении, в
сам промпт это закладывать не нужно.

Чек-лист (прозрачный фон/тень/угасающее белое свечение/квадрат/
читаемость силуэта) уже включён в промпт — не сокращать при
использовании.
