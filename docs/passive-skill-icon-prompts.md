# Иконки классонейтральных пассивок (6×6 рангов)

Фон — отдельный стиль от активных боевых скиллов (у тех тёпло-золотистый
фон «Атаки ястреба»). Для пассивок используется стиль уже существующих
иконок из `public/img/passives/` (shield.png, rage.png, stun.png и др.,
реально загруженные референсы): живописная полу-реалистичная RPG-иконка,
**глубокий электрически-синий радиальный фон** с яркими сине-голубыми
лучами/молниями, бьющими от центра наружу, тёмно-синяя виньетка только по
самым углам, символ в центре — металлик-серебристо-синего оттенка,
заполняет почти весь кадр, драматичное боковое освещение с ярким
контровым краем. Квадрат, 512×512, без текста/рамки/водяного знака.

Внутри каждой из 6 пассивок — единый визуальный мотив на все 6 рангов,
нарастающий по яркости/масштабу/детализации от ранга I к VI (как уже
делали для боевых скиллов и баффов).
