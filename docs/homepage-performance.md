# JavaScript главной страницы

Главная использует отдельную Vite-точку входа `resources/js/homepage.js`. Игровой интерфейс продолжает использовать `resources/js/app.js`. Общий код Echo/Pusher и счётчика онлайна Vite выделяет в разделяемый chunk; Axios в главную не импортируется.

На главной больше не подключаются `common.js`, `simple_alt.js`, jQuery, `vendors.min.js`, `lib.min.js`, Backbone, Underscore, Fancybox, Slick, Cufon, JS-шрифт Cambria, старые языковые словари/полифилы IE и неиспользуемый `counter.js`. Исходные файлы сохранены для страниц игры, которые их ещё используют.

## Замены

- `resources/js/homepage-ui.js`: переключение скриншотов, просмотр в native dialog, стрелки/клавиатура, возврат фокуса, окна информации об игровых объектах, таймер. Таймер приостанавливается в скрытой вкладке и пересчитывается при возврате.
- `resources/css/homepage.css`: стили галереи/просмотрщика и золотой текст заголовков через CSS вместо canvas/Cufon, общий стек Cambria/Georgia с поддержкой RU/UK.
- `news::partials.screenshots` и `news::partials.lightbox`: семантические ссылки на оригиналы, размеры изображений, lazy loading миниатюр и локализованные подписи. Исходные семь PNG и пути к ним сохранены. Оптимизация самих картинок — отдельная задача.
- Общий `public/js/item_tooltip.js` сохранён с отложенной загрузкой; главная задаёт только требуемые ему хелперы и переводы. Фальшивый `main_frame` и неиспользуемая обработка эффектов удалены.
- `public/js/prelaunch.js`: существующая модалка подписки продолжает работать.
- Публичный канал онлайна запрашивает текущее значение через Pusher `subscription.trigger()`: метода `whisper()` у публичного Echo-канала нет.

## Проверка 06.11.2026

Набор подключаемого JavaScript сокращён с приблизительно 1 МБ до 111 КиБ без сжатия, включая общий WebSocket chunk, тултипы, подписку и защиту сессии. Прямых script-тегов стало 4 вместо 19; разделяемый модуль дополнительно загружается через modulepreload. Это не оценка общего веса страницы или Core Web Vitals: изображения и основные CSS не оптимизировались.

В Chrome проверены RU/UK, открытие модалки подписки, выбор скриншота, переходы просмотрщика и работа тултипа без jQuery. В новой странице исключений JavaScript не зафиксировано. Сборка `npm run build`, 12 JS-тестов и 11 PHP-тестов на SQLite в памяти прошли.

Для развёртывания обязательно собирать все Vite-входы вместе:

```bash
npm run build
```
