# Промпты для иконок замкнутых сундуков (профессия «Взломщик», 6 тиров × 3 варианта ловушки = 18 предметов)

Визуальная система: **материал/конструкция сундука эскалирует по тиру** (1→6, от потрёпанного дерева до потусторонней бездны), а **вид ловушки** — отдельный слой поверх (нет / ослабляющая / усиленная), одинаковый принцип на каждом тире:
- **Нет ловушки** — чистый замок, без дополнительных меток.
- **Ослабляющая ловушка** — тусклое болезненно-зелёное/фиолетовое свечение или предупреждающий символ у замка.
- **Усиленная ловушка** — угрожающие светящиеся красные руны/шипы у замка.

Каждый промпт включает фиксированный чек-лист (прозрачный фон/белая обводка+угасающее свечение/квадрат/читаемость силуэта), без тёмной тени снизу. Не сокращать при использовании.
