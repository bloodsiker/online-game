# Промпты для иконок сета «Призрачный» (Тир3, uncommon)

Общий арт-стиль сета: эфемерный, полупрозрачный призрак-охотник — тонкие, будто нематериальные силуэты (уворотный архетип). Полупрозрачная бледно-голубовато-серебристая сталь с лёгким призрачным туманом/дымкой у краёв, лёгкое собственное свечение самого материала (не просто общий чек-лист-эффект, а часть материала предмета). Единая палитра по всем 10 предметам: бледно-серебристо-голубой + полупрозрачный дым + холодный белый.

Каждый промпт уже включает фиксированный чек-лист (прозрачный фон/угасающее белое свечение/квадрат/читаемость силуэта) — **без тёмной тени снизу** (по запросу, как и у Титана). Не сокращать при использовании.

## 1. Призрачный клинок (оружие, одноручное)
```
Ethereal spectral blade, "Phantom" themed fantasy game weapon icon. Semi-transparent pale silvery-blue steel blade with wispy ghostly mist trailing from the edges, faint inner glow within the metal itself, thin and elegant silhouette, no ornamentation, looks barely tethered to the physical world. Isolated on a fully transparent background, PNG format, item only, no background elements, no drop shadow. A soft white glow radiating from the item's silhouette that gradually fades outward into the transparent background, separating it clearly from any background it gets placed over.
```
